# Лабораторна робота №3: Java Stream API, Optional та Stream Gatherers

## Опис проєкту
Сервіс аналітики потоку транзакцій електронної комерції (`TransactionStreamAnalyzer`), який демонструє безпечне та ефективне опрацювання нескінченних послідовностей даних у Java 25 без блокування виконання:
- пошук першої транзакції понад заданий поріг (`findFirst` + `Optional`);
- накопичення транзакцій у межах бюджету через операцію короткого замикання (`takeWhile`);
- розбиття нескінченного потоку на фіксовані вікна (батчі) з обмеженням кількості пакетів за допомогою власного статевого `Gatherer` (`Gatherer.ofSequential`).
